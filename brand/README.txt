────────────────────────────────────────
RULES
────────────────────────────────────────

Clear space   Keep free space on all sides equal to one quarter of
              the icon's width. Nothing crosses it.

Minimum size  16px for the icon. Below that, use the bare tilde
              (svg/icon/tilde-bare-coral.svg) on a transparent ground.

The ñ         In every lockup the ñ stays coral. It is the thread
              back to the icon. Do not set the wordmark in one flat
              colour, and do not replace the ñ with a plain n — the
              spelling is part of the mark.

Role line     Set as FUNCTIONAL ARCHITECT · AI IN SDLC, uppercase,
              medium weight, wide tracking. Use the interpunct, not
              a comma, and never break it over two lines.

Never         Stretch or squash it. Rotate it. Add a shadow, gradient
              or outline. Recolour the field to purple. Place the
              coral icon on a coral ground (use icon-reverse instead).

────────────────────────────────────────
PNG BACKGROUNDS
────────────────────────────────────────

All PNGs have transparent backgrounds. The -dark files carry cream
text and are meant for dark grounds; they will be invisible on white.

────────────────────────────────────────
SVG TEXT
────────────────────────────────────────

Lockup and wordmark SVGs use live text set in Poppins SemiBold (600),
a free Google font. If the viewer does not have Poppins installed the
text falls back to Helvetica/Arial and the spacing will be slightly
off — use the matching PNG in that situation, or install Poppins:
https://fonts.google.com/specimen/Poppins

The icon SVGs contain no text and are safe everywhere.
